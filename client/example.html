pages-storage example

A tiny app that keeps text files in your own GitHub repo. Everything below runs in your browser.

Sign in with GitHub to browse a repo and edit its text files, or try the demo, which keeps fake files in this browser.

Real sign-in is off until you fill in CONFIG in this file.
